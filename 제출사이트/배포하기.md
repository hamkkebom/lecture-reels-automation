# 강의 영상 제출 사이트 배포하기

## 구조

1. 제출하는 사람이 사이트에서 제출 코드, 이름, 강의 제목을 넣고 원본 영상을 올립니다.
2. 영상은 Cloudflare R2에 50MB 조각으로 나뉘어 바로 저장됩니다.
3. 내 PC에서 `제출받기.py`가 새 제출을 받아 `원본/제출/`에 저장하고, 사이트 쪽 원본을 지웁니다.
4. 작업과 결과 전달은 지금처럼 내가 합니다.

비용: Cloudflare 무료 구간 안에서 사실상 0원입니다(R2 저장 월 10GB 무료, 받아 오는 전송료 0원). 다만 R2를 켜려면 결제 카드를 등록해야 합니다.

## 처음 한 번만 (사장님이 직접 할 일)

1. https://dash.cloudflare.com 에서 계정을 만듭니다.
2. 왼쪽 메뉴 R2에서 결제 카드를 등록하고 R2를 켭니다.

## 배포 (Claude에게 "배포해줘"라고 하면 아래를 실행)

```powershell
cd "D:\dev\113. 영상편집자동화\제출사이트"
npx wrangler login                     # 브라우저가 열리면 사장님이 로그인·허용
npx wrangler r2 bucket create lecture-submit
npx wrangler r2 bucket lifecycle add lecture-submit 원본3일삭제 raw/ --expire-days 3 --abort-multipart-days 1 -y
npx wrangler secret put SUBMIT_CODE    # 제출하는 사람들에게 알려 줄 코드
npx wrangler secret put ADMIN_TOKEN    # 내 PC용 열쇠 (40자 정도, 남에게 알리지 않음)
npx wrangler deploy                    # 끝나면 https://lecture-submit.<계정>.workers.dev 주소가 나옴
```

배포 후 `제출받기_설정.json`의 `url`을 나온 주소로, `token`을 ADMIN_TOKEN 값으로 바꿉니다.

## 현재 배포 상태 (2026-11-21)

- 주소: https://lecture-submit.<계정>.workers.dev (실제 주소는 `제출받기_설정.json`의 `url`)
- 제출 코드: `제출코드.txt` 참고 (ADMIN_TOKEN은 `제출받기_설정.json`에만 있음)
- 자동 삭제 규칙 `expire-raw-3d` 적용됨

## 평소 사용

- 바탕화면 **제출 받기 켜기**: 더블클릭해 창을 켜 두면 5분마다 새 제출을 `원본/제출/`로 받아 옵니다.
- 바탕화면 **제출 관리**: 관리자 페이지(`/admin`)가 열립니다. 관리자 비밀번호로 로그인하면 그 브라우저는 30일 동안 다시 묻지 않습니다.
  - 10분 안에 10번 틀리면 10분 동안 잠깁니다 (내 PC 받아오기는 그대로 동작).
  - 비밀번호 바꾸기: `npx wrangler secret put ADMIN_PASSWORD` (Claude에게 "관리자 비밀번호 바꿔줘")
  - 제출 목록, 상태(새 제출 → PC로 받음 → 작업 중 → 완료), 메모
  - 내려받기, 원본 삭제, 기록 삭제
  - 내 PC 받아오기가 켜져 있는지 표시
  - 안내 문구 복사, 제출 코드 바꾸기 (바꾸면 30초 안에 반영)

## 학원

- 관리자 페이지 '학원'에서 학원을 추가합니다: 이름, 전용 제출 코드, 스타일 틀, 색 3가지, 구글드라이브 폴더, 로고(투명 PNG).
- 제출 코드로 어느 학원인지 자동 구분됩니다. 받은 원본은 `원본/제출/<학원>/`에 저장됩니다.
- 학원별 '안내 문구 복사'로 그 학원 코드가 담긴 안내를 보냅니다.
- 학원이 하나라도 있으면 예전 공용 코드는 쓰이지 않습니다. 승리어학원은 기존 공용 코드 그대로 등록돼 있습니다.

## 진행 상태

새 제출 → PC로 받음(자동) → 작업 중(받아쓰기를 시작하면 자동) → 편집 끝(전달 전) → 완료(전달, 직접)

- 편집 끝 표시: `.venv\Scripts\python submit_status.py <원본 파일|이름 일부> 편집끝 --memo "릴스 5개"`
- 관리자 페이지에서 언제든 직접 바꿀 수도 있습니다.

## 검토와 드라이브 전달

1. 편집이 끝나면 `submit_status.py <원본|이름 일부> 편집끝 --reels output\...mp4 ...` → 릴스가 `완성\<학원>\<제출 이름>\`에 모이고 관리자 페이지에 '편집 끝 · 릴스 N개'가 뜹니다.
2. 사장님이 `완성\` 폴더에서 검토합니다.
3. 관리자 페이지에서 **드라이브로 전달** → 내 PC가 5분 안에 학원 드라이브 폴더/<제출 이름>/ 으로 올리고 '완료(전달)'로 바꿉니다. 실패하면 '편집 끝'으로 돌아가고 메모에 이유가 남습니다.
- 드라이브 연결은 rclone(리모트 이름 `gdrive`)을 씁니다. 연결 확인: `.venv\Scripts\python deliver.py --check`
- rclone 설정 파일은 `%USERPROFILE%\.config\rclone\rclone.conf` 에 둡니다 (스토어판 Python이 AppData 설정을 못 봄). 다시 로그인: `rclone --config "%USERPROFILE%\.config\rclone\rclone.conf" config reconnect gdrive:`
- 작업 PC를 바꿀 때 이 설정 파일도 함께 옮기거나 새 PC에서 다시 로그인합니다.
- 주의: 지금은 rclone 공용 구글 클라이언트를 쓰는데, rclone 측이 2026년 중 중단 예정이라고 알립니다. 전달이 '드라이브 올리기 오류'로 실패하기 시작하면 내 구글 클라이언트 ID를 만들어 바꿔야 합니다.
- 학원 드라이브 폴더는 사장님 구글 계정에 '편집자' 권한으로 공유되어 있어야 합니다.

## 정산

- 관리자 페이지 **정산** 칸: 달을 고르면 학원별 강의 수·릴스 수와 합계가 나옵니다.
- 장부에 잡히는 때: 제출이 '완료(전달)'가 되고 릴스가 1개 이상일 때 (드라이브 전달이든 상태를 직접 '완료'로 바꾸든).
- 처음 완료된 달(한국 시간)에 잡힙니다. '다시 전달'해도 두 번 세지 않고 그 달 그대로입니다.
- 제출 기록을 지워도 정산 장부는 남습니다.
- **자세히**: 건마다 릴스 수 고치기, 정산 달 옮기기(예: 월말 늦은 건을 다음 달로), 정산에서 빼기.
- **엑셀로 받기**: `정산_2026-11.csv` (위에 학원별 합계, 아래에 건별 목록). 엑셀에서 바로 열립니다.

## 텔레그램 알림

- 새 제출이 들어오거나 드라이브 전달이 실패하면 휴대폰 텔레그램으로 알려 줍니다. PC가 꺼져 있어도 옵니다.
- 연결 방법 (관리자 페이지 **텔레그램 알림** 칸에도 적혀 있음):
  1. 텔레그램에서 @BotFather → `/newbot` → 봇 이름을 정하면 토큰(숫자:글자)을 줍니다.
  2. 만든 봇을 찾아 '시작'을 누릅니다.
  3. 토큰을 관리자 페이지에 붙여 넣고 **연결** → 시험 메시지가 옵니다.
- 토큰은 사이트 저장소에만 두고 화면에 다시 보여 주지 않습니다. 토큰이 새어 나가면 BotFather에서 `/revoke`로 바꾸고 다시 연결합니다.

## 강사 동의 확인

- 제출 화면에 "영상에 나오는 강사에게 촬영·편집·홍보 이용 동의를 받았습니다" 체크 칸이 있고, 체크해야 제출됩니다.
- 체크한 시각이 기록에 남고, 관리자 페이지 제출 목록에 '강사 동의 확인함'으로 보입니다.
- 이 체크는 학원이 동의를 받았다는 확인입니다. 실제 동의서는 학원과의 계약서에 함께 넣어 두는 것이 안전합니다.

## PC 파일 자동 정리

- '제출 받기 켜기' 창이 한 시간에 한 번, '완료(전달)'된 지 7일 지난 제출의 원본 영상(`원본/제출/<학원>/…`)과 받아쓰기 폴더(`work/<받은 파일 이름>/`)를 지웁니다.
- 완성 릴스(`완성/`)와 직접 만든 다른 `work/` 폴더는 지우지 않습니다.
- 상태를 다시 '작업 중' 등으로 돌리면 지우지 않습니다.
- 미리 보기: `.venv\Scripts\python 정리하기.py --dry-run`

## 작업 컴퓨터를 바꿀 때

1. 새 PC에 Python을 설치합니다 (https://www.python.org/downloads/).
2. 프로젝트 폴더를 통째로 복사합니다. `제출받기_설정.json`이 꼭 함께 있어야 합니다.
3. 새 PC에서 `제출받기_설치.bat`을 더블클릭합니다. 사이트 연결을 확인하고, 시작프로그램 등록과 바탕화면 아이콘을 만듭니다.
4. 예전 PC에서는 Win+R → `shell:startup`을 열어 '제출 받기 켜기'를 지웁니다. 두 PC가 다 켜져 있으면 제출을 나눠 받게 됩니다.

## 자동 삭제

- 1차: 내 PC가 다 받은 뒤 사이트 쪽 원본을 바로 지웁니다.
- 2차(안전망): 3일이 지나면 R2가 저절로 지웁니다. 올리다 중단된 조각은 1일 뒤 지웁니다. R2 삭제는 만료 후 보통 24시간 안에 처리됩니다.
- 3차: 내 PC의 `원본/제출/` 원본은 '완료(전달)' 7일 뒤 자동으로 지웁니다 (위 'PC 파일 자동 정리').

## 주의

- 제출 코드가 새면 바꾸세요: `npx wrangler secret put SUBMIT_CODE`
- 강사 얼굴과 목소리가 담긴 영상이라, 제출 화면 동의 체크와 별개로 학원과의 계약서에 촬영·홍보 이용 동의를 넣어 두는 것이 안전합니다.
- R2는 한국 리전이 없어 영상이 잠시 해외에 보관됩니다.
